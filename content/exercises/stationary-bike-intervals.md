  - Set a resistance that makes the "on" interval genuinely hard
  - Keep cadence high and controlled, not bouncing in the seat
  - Use the "off" interval to actually recover, not coast at speed
common_faults:
  - Resistance too low, so intervals don't feel different from steady state
  - Standing/bouncing instead of a stable seated cadence
  - Not resetting the interval timer, drifting into steady-state riding

## Setup
Set the bike seat height so the knee has a slight bend at the bottom of the
pedal stroke. Set a moderate base resistance.

## Execution
Alternate between a hard "on" interval at high resistance/cadence and an
easier "off" interval to recover, repeating for the prescribed number of
rounds.
